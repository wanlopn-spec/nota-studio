## 1. เริ่มต้นใช้งาน

NOTA STUDIO (GW) เป็นโปรแกรมเขียนโน้ตดนตรีสากลที่ทำงานบนเว็บเบราว์เซอร์ ไม่ต้องติดตั้งอะไร เปิดลิงก์แล้วใช้งานได้ทันที แนะนำให้ใช้บนคอมพิวเตอร์ เพราะคำสั่งส่วนใหญ่มีปุ่มลัดบนคีย์บอร์ด

เปิดแอปได้ที่ [NOTA STUDIO (GW)](https://wanlopn-spec.github.io/nota-studio/) ครั้งแรกจะเห็นเพลงตัวอย่าง “Bangkok Night Blues” กด **Space** เพื่อฟังได้เลย

### ส่วนต่าง ๆ ของหน้าจอ

| ส่วน | ตำแหน่ง | ใช้ทำอะไร |
| --- | --- | --- |
| แถบบนสุด | บนสุด | ชื่อเพลง, ช่องค้นหาคำสั่ง (Ctrl+K), ปุ่มสร้างใหม่ เปิดไฟล์ เลิกทำ ทำซ้ำ |
| แท็บ | ใต้แถบบน | บันทึกโน้ต, สัญลักษณ์, ข้อความ, เครื่องดนตรี & ห้อง, จัดหน้า, เล่น, ส่งออก |
| ริบบอนเครื่องมือ | ใต้แท็บ | ปุ่มคำสั่งของแท็บที่เลือก |
| พาเลต | ซ้าย | กุญแจ บันไดเสียง อัตราจังหวะ สัญลักษณ์ต่าง ๆ พร้อมช่องค้นหา |
| กระดาษโน้ต | กลาง | พื้นที่เขียนและแก้ไขโน้ต |
| แผงขวา | ขวา | คุณสมบัติของสิ่งที่เลือก, เครื่องดนตรี, มิกเซอร์, ข้อมูลหน้า |
| แถบเล่นเสียง | ล่าง | เล่น/หยุด วนซ้ำ เมโทรนอม เวลา tempo ระดับเสียง |
| แถบสถานะ | ล่างสุด | โหมดปัจจุบัน สิ่งที่เลือก บันไดเสียง เสียง (voice) ซูม มุมมอง |

บนมือถือ พาเลตและแผงขวาจะซ่อนอยู่ เปิดด้วยปุ่ม ☰ และ ◧ ที่แถบบน

### การบันทึกงาน

ทุกการแก้ไขจะบันทึกอัตโนมัติไว้ในเบราว์เซอร์เครื่องนั้น เปิดหน้าใหม่ก็จะกลับมาที่งานเดิม หากต้องการย้ายงานไปเครื่องอื่นหรือเก็บสำรอง ให้ส่งออกเป็นไฟล์โปรเจกต์ (Ctrl+S) ดูหัวข้อ 9

## 2. สร้างสกอร์ใหม่และจัดการเครื่องดนตรี

กดปุ่ม **＋ ใหม่** (Ctrl+N) เลือกเทมเพลต กรอกชื่อเพลง ผู้ประพันธ์ บันไดเสียง อัตราจังหวะ tempo และจำนวนห้อง แล้วกด **สร้างสกอร์**

| เทมเพลต | เครื่องดนตรี |
| --- | --- |
| Solo piano | Piano |
| Lead sheet | Voice (ใส่คอร์ดเพิ่มเอง) |
| String quartet | Violin ×2, Viola, Cello |
| SATB choir | Soprano, Alto, Tenor, Bass, Piano |
| Jazz combo | Alto Sax, Trumpet, Trombone, Piano, Contrabass, Drum Set |
| Big band | Sax ×5, Trumpet ×4, Trombone ×4, Guitar, Piano, Bass, Drums |
| Rock band | Vocal, Electric Guitar ×2, Electric Bass, Drums |
| Orchestra | Fl, Ob, Cl, Bsn, Hn, Tpt, Tbn, Timpani, Vln ×2, Vla, Vc, Cb |
| Wind quintet | Fl, Ob, Cl, Hn, Bsn |
| ว่าง | Flute หนึ่งเครื่อง |

### เพิ่ม ลบ และเรียงเครื่องดนตรี

- **เพิ่ม:** กด **I** หรือแท็บ “เครื่องดนตรี & ห้อง” → **＋ เพิ่ม** แล้วค้นหาชื่อ มีให้เลือก 36 ชนิด แบ่งตามกลุ่ม เปียโน ออร์แกน ฮาร์ป จะได้ 2 บรรทัดพร้อมวงเล็บปีกกา
- **เปลี่ยนชื่อ เลื่อน ลบ:** แผงขวา → แท็บ **เครื่องดนตรี** พิมพ์ชื่อใหม่ในช่อง ใช้ปุ่ม ↑ ↓ เพื่อเรียงลำดับ และ ✕ เพื่อลบ
- เครื่องดนตรีกลุ่มเดียวกันที่อยู่ติดกัน (เช่น แซกโซโฟน, เครื่องทองเหลือง, เครื่องสาย) จะมีวงเล็บเหลี่ยมรวมกลุ่มให้อัตโนมัติ

### เครื่องทรานสโพสและ Concert pitch

เครื่องอย่าง Trumpet in B♭, Alto Sax (E♭), Horn in F จะแสดงโน้ตตามที่ผู้เล่นอ่าน (written pitch) โดยค่าเริ่มต้น ส่วนเสียงที่เล่นออกมาเป็นเสียงจริง (concert pitch)

- กดชิป **Transposed / Concert pitch** ที่แถบแท็บ หรือปุ่ม **Concert** ที่แถบสถานะ เพื่อสลับการแสดงผล
- โหมด Concert pitch ยังคงการทรานสโพสระดับออกเทฟไว้ เช่น กีตาร์ เบส Piccolo
- การสะกดโน้ตทรานสโพสตามขั้นคู่ เช่น D♭ เสียงจริงบน Alto Sax จะแสดงเป็น B♭ ไม่ใช่ A♯

## 3. การใส่โน้ต

การใส่โน้ตทำในโหมดใส่โน้ต โดยเลือกค่าตัวโน้ตก่อน แล้วพิมพ์ชื่อโน้ต A–G แอปจะเลือกออกเทฟที่ใกล้โน้ตก่อนหน้าที่สุด และเลื่อนเคอร์เซอร์ไปตำแหน่งถัดไปเอง

1. คลิกโน้ตหรือห้องที่ต้องการเริ่มเขียน
2. กด **N** เข้าโหมดใส่โน้ต เคอร์เซอร์สีส้มจะปรากฏบนบรรทัด
3. กดตัวเลขเลือกค่าตัวโน้ต (ตารางด้านล่าง) และกด **.** หากต้องการโน้ตประจุด
4. พิมพ์ **A B C D E F G** เพื่อใส่โน้ต หรือ **0** เพื่อใส่ตัวหยุด
5. กด **Esc** เพื่อออกจากโหมดใส่โน้ต

| ปุ่ม | ค่าตัวโน้ต |
| --- | --- |
| 7 | ตัวกลม (whole) |
| 6 | ตัวขาว (half) |
| 5 | ตัวดำ (quarter) |
| 4 | เขบ็ต 1 ชั้น (eighth) |
| 3 | เขบ็ต 2 ชั้น (16th) |
| 2 | เขบ็ต 3 ชั้น (32nd) |
| 1 | เขบ็ต 4 ชั้น (64th) |

### ปรับระดับเสียงและเครื่องหมายแปลงเสียง

- **↑ / ↓** เลื่อนขึ้นลงครึ่งเสียง **Ctrl+↑ / Ctrl+↓** เลื่อนหนึ่งออกเทฟ
- ปุ่ม ♯ ♭ ♮ 𝄪 𝄫 ในแท็บบันทึกโน้ตหรือพาเลต ใช้กำหนดเครื่องหมายแปลงเสียงให้โน้ตที่เลือก
- ตัวอักษรจะใช้เครื่องหมายตามบันไดเสียงอัตโนมัติ เช่น พิมพ์ F ในบันไดเสียง G major จะได้ F♯

### คอร์ด tie และ triplet

- **Shift + ตัวอักษร** เพิ่มโน้ตซ้อนลงในโน้ตที่เพิ่งใส่ เพื่อสร้างคอร์ด
- **T** ในโหมดใส่โน้ตจะใส่โน้ตเสียงเดียวกันต่อและผูก tie ให้ นอกโหมดใส่โน้ตจะเปิด/ปิด tie ของโน้ตที่เลือก
- **Ctrl+3** เปิดโหมด triplet แล้วใส่โน้ต 3 ตัวในเวลา 2 ตัว
- โน้ตที่ยาวเกินห้องจะถูกแยกเป็นโน้ตผูก tie ข้ามเส้นกั้นห้องให้อัตโนมัติ และเมื่อเขียนถึงห้องสุดท้าย แอปจะเพิ่มห้องใหม่ให้เอง

### ใช้เมาส์

ในโหมดใส่โน้ต คลิกบนเส้นหรือช่องของบรรทัดเพื่อวางโน้ตตามระดับเสียงที่คลิก Shift+คลิกเพื่อซ้อนเป็นคอร์ด

นอกโหมดใส่โน้ต การกดตัวเลขจะเปลี่ยนค่าตัวโน้ตที่เลือก และการพิมพ์ตัวอักษรบนโน้ตที่เลือกจะเข้าโหมดใส่โน้ตทันที

## 4. หลายเสียง (Multi-voice)

แต่ละบรรทัดเขียนได้สูงสุด 4 เสียงพร้อมกัน เช่น ทำนองกับแนวประสานบนบรรทัดเดียว หรือกลองที่แยกมือกับเท้า เสียง 1 และ 3 ก้านโน้ตชี้ขึ้น เสียง 2 และ 4 ก้านโน้ตชี้ลง

| เสียง | สีเคอร์เซอร์ | ก้านโน้ต | ปุ่มลัด |
| --- | --- | --- | --- |
| 1 | ส้ม | ขึ้น | Ctrl+Alt+1 |
| 2 | เขียว | ลง | Ctrl+Alt+2 |
| 3 | น้ำเงิน | ขึ้น | Ctrl+Alt+3 |
| 4 | ม่วง | ลง | Ctrl+Alt+4 |

### เขียนเสียงที่ 2

1. วางเคอร์เซอร์ที่จังหวะที่ต้องการ แล้วกด **N**
2. กด **Ctrl+Alt+2** หรือปุ่ม **เสียง (Voice) 2** ในแท็บบันทึกโน้ต
3. ใส่โน้ตตามปกติ เคอร์เซอร์จะเป็นสีเขียว
4. กด **Ctrl+Alt+1** เพื่อกลับไปเขียนเสียงหลัก

### ย้ายโน้ตข้ามเสียง

ออกจากโหมดใส่โน้ต คลิกเลือกโน้ต แล้วกด Ctrl+Alt+1–4 หรือใช้ปุ่ม **ย้ายไปเสียง** ในแผงคุณสมบัติ ตำแหน่งเดิมจะกลายเป็นตัวหยุด

ถ้าลบโน้ตในเสียง 2–4 จนเหลือแต่ตัวหยุดทั้งห้อง เสียงนั้นจะหายไปเอง

## 5. การเลือกและแก้ไข

| ต้องการเลือก | วิธี |
| --- | --- |
| โน้ตตัวเดียว | คลิกที่โน้ต |
| ทั้งห้อง | คลิกพื้นที่ว่างในห้อง |
| ช่วงโน้ต | เลือกโน้ตแรก แล้ว Shift+คลิกโน้ตสุดท้าย หรือ Shift+→ |
| หลายห้อง/หลายบรรทัด | คลิกห้องแรก แล้ว Shift+คลิกห้องสุดท้าย |
| ทั้งสกอร์ | Ctrl+A |

เลื่อนการเลือกด้วย ← → ไปทีละโน้ต Ctrl+← → ไปทีละห้อง และ Alt+↑ ↓ ไปบรรทัดบนหรือล่าง

### คัดลอก วาง ลบ

- **Ctrl+C / Ctrl+V** คัดลอกและวาง ทั้งแบบช่วงโน้ตและแบบทั้งห้อง
- **Delete** เปลี่ยนโน้ตที่เลือกเป็นตัวหยุด หรือล้างทั้งห้องที่เลือก
- **Ctrl+Z** เลิกทำ **Ctrl+Shift+Z** หรือ **Ctrl+Y** ทำซ้ำ

### ห้อง บันไดเสียง อัตราจังหวะ กุญแจ

- **Ctrl+B** เพิ่มห้องต่อท้าย **Insert** แทรกห้องก่อนห้องที่เลือก **Ctrl+Delete** ลบห้องที่เลือก
- เปลี่ยนบันไดเสียงหรืออัตราจังหวะกลางเพลง: เลือกห้อง แล้วคลิกในพาเลต หรือแก้ในแผงคุณสมบัติ เมื่อเปลี่ยนอัตราจังหวะ โน้ตที่เกินความยาวห้องใหม่จะถูกตัดออก
- เปลี่ยนกุญแจ (Treble, Bass, Alto, Tenor, Treble 8vb): เลือกโน้ตหรือห้องในบรรทัดนั้น แล้วคลิกกุญแจในพาเลต

### Transpose

แท็บ “เครื่องดนตรี & ห้อง” → **Transpose** เลือกทิศทางขึ้นหรือลง เลือกขั้นคู่ และขอบเขต (ทั้งสกอร์หรือช่วงที่เลือก) คอร์ดสัญลักษณ์จะย้ายตาม ส่วน Drum Set ไม่ถูกย้าย

## 6. สัญลักษณ์และข้อความ

เลือกโน้ตหรือช่วงก่อน แล้วคลิกสัญลักษณ์ในแท็บ “สัญลักษณ์” หรือในพาเลตด้านซ้าย คลิกซ้ำเพื่อเอาออก

| หมวด | รายการ | วิธีใส่ |
| --- | --- | --- |
| Articulation | Staccato, Tenuto, Accent, Marcato, Staccatissimo, Fermata | เลือกโน้ต แล้วคลิก |
| Dynamics | ppp – fff, sfz, fp, sf, rfz | เลือกโน้ต แล้วคลิก |
| Slur | เส้นโค้งเชื่อมโน้ต | เลือกช่วงโน้ต แล้วกด **S** |
| Hairpin | Crescendo / Diminuendo | เลือกช่วงโน้ต แล้วกด **<** หรือ **>** |
| เส้นกั้นห้อง | คู่, จบ, เริ่มย้อน, จบย้อน | เลือกห้อง แล้วคลิก |
| ป้ายนำทาง | D.C. al Fine, D.S. al Coda, Fine, Segno, Coda | เลือกห้อง แล้วคลิกในพาเลต |

### ข้อความ

| ข้อความ | ปุ่มลัด | หมายเหตุ |
| --- | --- | --- |
| เนื้อร้อง | Ctrl+L | Space หรือ Tab ไปโน้ตถัดไป, ขีด - ตัดพยางค์ |
| คอร์ด | Ctrl+Shift+K | เช่น Cmaj7, F#m7b5 · Space ไปตัวถัดไป |
| Staff text | Ctrl+T | เช่น pizz., solo |
| Rehearsal mark | Ctrl+M | ตัวอักษรถัดไปจะเติมให้อัตโนมัติ |
| Tempo | Alt+T | พิมพ์เช่น “Allegro 132” หรือ “96” |
| ชื่อเพลง ผู้ประพันธ์ | ดับเบิลคลิกบนหัวกระดาษ | หรือแก้ในแผงขวา แท็บ **หน้า** |

กด **Enter** เพื่อบันทึก **Esc** เพื่อยกเลิก ข้อความเหล่านี้แก้ไขในแผงคุณสมบัติได้เช่นกัน

## 7. จัดหน้าและมุมมอง

- **มุมมอง:** หน้ากระดาษ (Page view) หรือต่อเนื่องแนวนอน (Continuous) สลับได้ที่แท็บ “จัดหน้า” หรือแถบสถานะ
- **ซูม:** Ctrl+= / Ctrl+- หรือ Ctrl+ล้อเมาส์ ปุ่ม **พอดี** ปรับให้กระดาษเต็มความกว้างจอ
- **ตัดบรรทัด:** เลือกห้อง แล้วกด **Enter** เพื่อขึ้นระบบบรรทัดใหม่หลังห้องนั้น
- **ห้องต่อบรรทัด:** อัตโนมัติ หรือกำหนดเป็น 2–8 ห้อง
- **ระยะ:** ปรับระยะห่างบรรทัด ระยะระบบ และความกว้างโน้ตได้ด้วยแถบเลื่อน ระยะระหว่างบรรทัดจะขยายเองเมื่อมีโน้ตสูงต่ำ คอร์ด หรือเนื้อร้อง
- **ซ่อนบรรทัดว่าง:** ซ่อนเครื่องดนตรีที่ไม่มีโน้ตในระบบนั้น (ยกเว้นระบบแรก)
- **เลขห้อง:** แสดงต้นบรรทัด ทุกห้อง หรือไม่แสดง (แผงขวา แท็บ **หน้า**)
- **Part:** เลือกเครื่องดนตรีเดียวจากช่อง Part ในแท็บ “จัดหน้า” เพื่อดูโน้ตแยกสำหรับผู้เล่นคนนั้น

## 9. นำเข้าและส่งออก

### นำเข้า

กด **Ctrl+O** หรือปุ่ม **เปิด** หรือลากไฟล์มาวางบนกระดาษโน้ต รองรับไฟล์ MusicXML (.musicxml, .xml), MusicXML แบบบีบอัด (.mxl) และไฟล์โปรเจกต์ NOTA STUDIO (GW) (.json) ไฟล์จาก MuseScore, Sibelius, Finale หรือ Dorico ส่งออกเป็น MusicXML แล้วเปิดได้

### ส่งออก (แท็บ “ส่งออก”)

| ปุ่ม | ไฟล์ที่ได้ | ใช้ทำอะไร |
| --- | --- | --- |
| ทั้งหมด .zip | MusicXML + MIDI + SVG ทุกหน้า + โปรเจกต์ | เก็บครบชุด |
| MusicXML | .zip ที่มี .musicxml | เปิดต่อใน MuseScore, Sibelius, Finale |
| MIDI | .zip ที่มี .mid | เปิดใน DAW หรือโปรแกรมเล่น MIDI |
| SVG | .svg (หลายหน้าเป็น .zip) | ภาพเวกเตอร์คมชัด ใช้พิมพ์หรือใส่เอกสาร |
| PNG | .png (หลายหน้าเป็น .zip) | ภาพสำหรับแชร์ |
| โปรเจกต์ | .nota.json | สำรองงานหรือย้ายไปเครื่องอื่น |
| คัดลอก MusicXML | ข้อความในคลิปบอร์ด | วางลงไฟล์ .musicxml เองได้ |

ไฟล์ MusicXML และ MIDI จะอยู่ในไฟล์ .zip เพราะหน้าเว็บนี้บันทึกนามสกุลเหล่านั้นตรง ๆ ไม่ได้ ต้องแตกไฟล์ zip ก่อนนำไปใช้ ทุกครั้งที่บันทึก เบราว์เซอร์จะถามยืนยันก่อน

## 11. ข้อจำกัดและคำถามที่พบบ่อย

### ยังทำไม่ได้

- Grace note, ottava (8va), pedal, volta 1./2., multi-measure rest
- Tablature และ chord diagram ของกีตาร์
- เขียนโน้ตด้วยลายมือแบบ StaffPad
- ส่งออก PDF โดยตรง (ใช้ SVG หรือ PNG แทน)
- ซ่อนตัวหยุดเฉพาะตัวในเสียง 2–4
- Dynamics และเนื้อร้องของหลายเสียงที่จังหวะเดียวกันอาจซ้อนกัน

### คำถามที่พบบ่อย

**เปิดเครื่องอื่นแล้วงานหาย?** งานบันทึกไว้ในเบราว์เซอร์เครื่องที่ใช้อยู่เท่านั้น ให้ส่งออกไฟล์โปรเจกต์ (Ctrl+S) แล้วเปิดในอีกเครื่อง

**อยากกลับไปเพลงตัวอย่าง?** กด Ctrl+K แล้วเลือก “Load sample score” งานปัจจุบันยังกด Ctrl+Z ย้อนกลับได้

**ไม่มีเสียง?** คลิกที่หน้าแอปหนึ่งครั้งก่อนกดเล่น เพราะเบราว์เซอร์อนุญาตเสียงหลังผู้ใช้โต้ตอบเท่านั้น และตรวจว่าไม่ได้ Mute เครื่องดนตรีในมิกเซอร์

**โน้ตทรานสโพสดูไม่ตรงกับเสียงจริง?** นั่นคือ written pitch ตามปกติ เปิด Concert pitch เพื่อดูเสียงจริง

**ปุ่มลัดไม่ทำงาน?** คลิกบนกระดาษโน้ตก่อน ถ้าเคอร์เซอร์อยู่ในช่องพิมพ์ ปุ่มลัดจะไม่ทำงาน
