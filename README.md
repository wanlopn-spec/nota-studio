# NOTA STUDIO (GW)

โปรแกรมเขียนโน้ตดนตรีสากลที่ทำงานบนเว็บเบราว์เซอร์ ไม่ต้องติดตั้ง แนวทางการใช้งานคล้าย MuseScore / Sibelius

## ความสามารถ

- ใส่โน้ตด้วยคีย์บอร์ด (A–G, 1–7, จุด, triplet, คอร์ด) หรือคลิกเมาส์
- เขียนได้ 4 เสียง (multi-voice) ต่อบรรทัด
- เครื่องดนตรี 36 ชนิด และเทมเพลต 10 แบบ (Big band, Orchestra, SATB ฯลฯ) รองรับเครื่องทรานสโพสและ Concert pitch
- Articulation, dynamics, slur, hairpin, tie, เส้นกั้นห้อง, เครื่องหมายย้อน, D.C./D.S./Coda
- เนื้อร้อง คอร์ด rehearsal mark tempo และข้อความต่าง ๆ
- เพิ่ม แทรก ลบห้อง เปลี่ยนบันไดเสียง อัตราจังหวะ กุญแจ และ transpose
- เล่นเสียงในเบราว์เซอร์ พร้อม swing เมโทรนอม วนช่วง และมิกเซอร์
- นำเข้า MusicXML / MXL และส่งออก MusicXML, MIDI, SVG, PNG, ไฟล์โปรเจกต์
- ปรับโทนสีแอปได้ 10 ธีม หรือเลือกสีเอง ทั้งโหมดมืดและสว่าง

## เปิดใช้งาน

เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือเปิดผ่าน GitHub Pages ของ repo นี้

ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดเอนจินเขียนโน้ต [VexFlow](https://www.vexflow.com/) และฟอนต์จาก Google Fonts

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/00-head.html` | หน้าตาแอป (HTML + CSS) |
| `src/10-engine.js` | โครงสร้างข้อมูลสกอร์ ทฤษฎีดนตรี เพลงตัวอย่าง |
| `src/20-render.js` | จัดหน้าและวาดโน้ตด้วย VexFlow |
| `src/30-edit.js` | คำสั่งแก้ไข การใส่โน้ต undo/redo |
| `src/40-io.js` | เล่นเสียง MIDI MusicXML zip การส่งออก |
| `src/50-ui.js` | ริบบอน พาเลต แผงคุณสมบัติ ธีม ปุ่มลัด |
| `build.sh` | รวมไฟล์ใน `src/` เป็น `index.html` |

แก้ไขไฟล์ใน `src/` แล้วรัน `./build.sh` เพื่อสร้าง `index.html` ใหม่
